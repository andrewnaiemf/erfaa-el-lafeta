# محطة لماذا أنا أرثوذكسي

لعبة تفاعلية — ارفع اللافتة الصح

**خدمة شباب وشابات كنيسة مارجرجس والأمير تادرس — المطار**  
**مؤتمر 2 (حتى يجده)**

**الآية:** «تمسّك بما عندك لئلا يأخذ أحد إكليلك» — رؤيا 3: 11

## اللعب أونلاين

افتح اللعبة من GitHub Pages بعد النشر.

## التشغيل محليًا

افتح ملف `index.html` في المتصفح (يشتغل من غير إنترنت).

## النشر على GitHub Pages

من داخل المجلد شغّل:

```bash
bash deploy-github-pages.sh
```
