# كورس: أنا أصنع صفحتي 🌐
## ويب + AI للأطفال (سن 9 تقريبًا) — 8 حصص

### ابدأ من هنا
افتح **`index.html`** في المتصفح — هتلاقي:
- **الكورس** — شرائح العرض على البروجektor
- **المواد** — مطبوعات · واجبات · أمثلة نتيجة البرومبت

### هيكل المجلد
| مجلد | الاستخدام |
|------|-----------|
| `course/` | شرائح HTML للعرض (`course/index.html`) + `teacher-guide.md` |
| `materials/` | كل حاجة للطباعة والأطفال (`materials/index.html`) |
| `materials/print/` | لوحة قصّ ولزّق + بطاقات + شهادات |
| `materials/examples/` | أمثلة حية = نتيجة تنفيذ البرومبت |
| `materials/homework/` | ملفات الواجب |
| `materials/prompts/` | برومبت لكل يوم/لعبة لوحده (+ محادثة التعديل جوه الملف) |

### قبل أول حصة
- متصفح (Chrome أو Firefox)
- Cursor أو ChatGPT (حساب للخادم)
- ورق + ألوان + مقص (للتمارين الورقية)
- ملف `index.html` فارغ لكل طفل (أو مجلد على Desktop)
