❌ اعمل موقع حلو بأي كود
✅ اعمل «صفحتي» بنفس الأجزاء: رأس + عني + بحب + حلمي + آية + زر — تاجات: h1 h2 p img div button فقط

برومبت الخادم (انسخ قدامهم)

اعمل ملف HTML واحد بالعربي dir=rtl اسمه صفحتي. الأجزاء بالترتيب: 1) رأس: صورة دائرية + h1 الاسم + p جملة قصيرة 2) قسم عني: h2 + p 3) قسم بحب: h2 + 4 صناديق (أيقونة + عنوان) 4) قسم حلمي: h2 + p 5) مربع آية + مرجع 6) زر «قل مرحبًا» مهم جدًا: استخدم فقط التاجات: h1, h2, p, img, div, button والستاييل فقط: color, background, font-size, border-radius, padding, text-align من غير مكتبات ومن غير تاجات تانية.
