# حصة 7 — موقع مركز الملاك ميخائيل

**النتيجة:** [`../examples/church-site/`](../examples/church-site/index.html)  
نفّذ **مرحلة مرحلة** — متلصقش الأربعة مرة واحدة.

المكان: كنيسة مارجرجس والأميرة تادرس — مطار النزهة  
المركز: مركز الملاك ميخائيل  
3 صفحات: الرئيسية · الأنشطة · تواصل معنا

---

## المرحلة 1 — الرئيسية

```
اعمل موقع تعريفي بسيط بالعربي dir="rtl" لـ «مركز الملاك ميخائيل»
التابع لكنيسة مارجرجس والأميرة تادرس — مطار النزهة.

دلوقتي اعمل الصفحة الرئيسية فقط (index.html) + ملف CSS واحد مشترك.

فيها:
- شريط اسم المركز والكنيسة فوق
- عنوان كبير: مركز الملاك ميخائيل
- فقرة قصيرة: مركز خدمي للأطفال والخدمة في الكنيسة
- 3 صناديق: مين إحنا / بنعمل إيه / فين مكاننا
- فوتر: اسم الكنيسة + مطار النزهة

تصميم هادي، ألوان كنسية بسيطة (أزرق غامق + ذهبي فاتح + أبيض).
خط واضح. مناسب للعرض على البروجektor قدام أطفال.
من غير مكتبات خارجية.
لسه متعملش الصفحتين التانيين — الرئيسية بس.
```

---

## المرحلة 2 — الأنشطة

```
ضيف صفحة تانية: activities.html
وربطها من شريط تنقّل في كل الصفحات: الرئيسية | الأنشطة | تواصل معنا

صفحة الأنشطة فيها 4 كروت على الأقل، مثلاً:
- اجتماع الأطفال
- كورس الويب (أنا أصنع صفحتي)
- ترانيم وأنشطة
- خدمة المركز

كل كرت: عنوان + جملة. نفس شكل الرئيسية.
```

---

## المرحلة 3 — التواصل

```
ضيف صفحة تالتة: contact.html
نفس الشريط فوق.

فيها:
- عنوان: تواصل معنا
- مكان: كنيسة مارجرجس والأميرة تادرس — مطار النزهة
- سطر: مركز الملاك ميخائيل
- مربع بسيط «رسالة» (اسم + جملة) من غير إرسال حقيقي — زر يقول «شكرًا! استلمنا كلامك»
- جملة ترحيب للأطفال وأهلهم
```

---

## المرحلة 4 — تلميع

```
في نفس الموقع، من غير ما تغيّر النصوص:
- خلّي الصفحة تبان كويس على اللابتوب والشاشة الكبيرة
- كبّر العناوين شوية
- الزر والروابط سهلة للمس
- ضيف أيقونة ملاك صغيرة في الهيدر (إيموجي كفاية)
- تأكد إن التنقّل بين الصفحات الثلاث شغال
اعرضلي الملفات الجاهزة للفتح في المتصفح.
```
