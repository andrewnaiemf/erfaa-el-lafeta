# حصة 5 — صفحتي 2.0

**النتيجة:** [`../examples/safhati-v5.html`](../examples/safhati-v5.html)  
ابدأ من صفحة الحصة 4 بعدين طوّرها.

---

## البرومبت النهائي (انسخ)

```
حدّث صفحة «صفحتي» لملف HTML واحد بالعربي dir="rtl".
دي نسخة 2.0 — لازم تبان أغنى وأجمل بكتير من النسخة البسيطة.

التصميم:
- خلفية غامقة فخمة (أزرق ليلي) مع لمسة ذهبية
- الصفحة أعرض (مش عمود ضيق)
- رأس كبير: صورة/إيموجي دائري + h1 الاسم + جملة قصيرة
- 3 صناديق أرقام صغيرة تحت الاسم: السن / عدد الهوايات / «حلم واحد»
- قسم عني: فقرة + قائمة ul/li بـ 4 حقائق
- قسم بحب: 4 كروت هوايات في شبكة 2×2 (أيقونة كبيرة + الاسم)
- قسم حلمي: شريط ملون عريض في النص
- مربع الآية بشكل أوضح
- زر «قل مرحبًا» كبير في الآخر

الحركة (مهم جدًا):
- كل كرت هواية يطلع لفوق ويكبر شوية لما الماوس ييجي عليه
- ظل قوي يتحرك مع الـ hover
- الزر يكبر ويلمع عند المرور عليه
- انتقال ناعم transition على الكروت والزر

مسموح: ul li span div h1 h2 p button img
ستاييل مسموح: flex أو grid، linear-gradient، box-shadow، transform، transition، hover، border-radius، ألوان فاقعة
من غير مكتبات خارجية. خط كبير لطفل 9 سنين.
الاسم: أندرو — نفس بيانات الحصة 4.
```

---

## محادثة التعديل (رسالة برسالة)

### رسالة 1 — من الحصة 4
استخدم برومبت [`day-04-safhati.md`](day-04-safhati.md) أو افتح النتيجة البسيطة.

### رسالة 2 — الشكل أقوى
```
في نفس الملف: خلّي الصفحة تبان أقوى بكتير.
خلفية غامقة أزرق ليلي، الصفحة أعرض،
وكروت الهوايات في شبكة 2×2 بأيقونات كبيرة.
```

### رسالة 3 — حركة
```
في نفس الملف: لما الماوس يعدّي على كرت الهواية يطلع لفوق شوية ويكبر،
والزر يلمع ويكبر. ضيف transition ناعم.
```

### رسالة 4 — تفاصيل
```
ضيف تحت الاسم 3 صناديق أرقام: السن / عدد الهوايات / حلم واحد،
وقائمة ul فيها 4 حقائق عني.
```
