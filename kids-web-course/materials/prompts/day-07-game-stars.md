# حصة 7 — لعبة صيّاد النجوم ⭐

**النتيجة:** [`../examples/game-stars.html`](../examples/game-stars.html)  
موصى به لسن 9.

---

## البرومبت النهائي (انسخ)

```
اعمل لعبة HTML واحدة بالعربي: نجوم تقع من فوق الشاشة.
الطفل يضغط النجمة قبل ما توصل الأرض (ضغطة واحدة فورًا).
كل نجمة = نقطة. 3 نجوم وقعت من غير ضغط = نهاية اللعبة.
بعد كل 20 نجمة اللعبة تبقى أسرع شوية.
زر «ابدأ» وزر «من جديد». اسم اللاعب يظهر فوق.
خط كبير، مناسب للمس، ملف واحد.
```

---

## محادثة التعديل (رسالة برسالة)

### رسالة 1 — البداية
```
اعمل لعبة HTML واحدة بالعربي: نجوم تقع من فوق.
اضغط النجمة قبل ما توصل الأرض.
كل نجمة = نقطة. 3 نجوم وقعت = نهاية.
زر ابدأ واسم اللاعب فوق. ملف واحد، مناسب للمس.
```

### رسالة 2 — الضغط
```
في نفس اللعبة: النجمة تتقبض من ضغطة واحدة فورًا
ومساحتها تبقى أكبر شوية للأطفال.
```

### رسالة 3 — التسريع
```
بعد ما اللاعب يجمع كل 20 نجمة، خلّي اللعبة أسرع شوية:
النجوم تقع أسرع وتظهر أسرع. واكتب جنب النقاط «أسرع!».
```
