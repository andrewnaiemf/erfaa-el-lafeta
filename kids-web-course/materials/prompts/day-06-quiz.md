## البرومبت النهائي (انسخ)

```
اعمل لعبة أسئلة HTML واحدة بالعربي dir="rtl" لطفل 9 سنين.

اسم اللعبة: مين يعرف أندرو؟
يظهر سؤال واحد + 4 أزرار إجابات.
الصح: ✅ ونقطة. الغلط: ❌ ونكمّل.
في الآخر: النتيجة من 5 + زر إعادة.

الأسئلة (★ = الصح):
1) لوني المفضل؟ أزرق★ / أحمر / أخضر / أصفر
2) بحب؟ كرة القدم★ / سباحة / طبخ / شطرنج
3) عندي كام سنة؟ 8 / 9★ / 10 / 11
4) حلمي؟ أعمل لعبة ويب★ / طيار / طبيب / معلم
5) كنيستي؟ مارجرجس مطار النزهة★ / مكان تاني / مكان تالت / مكان رابع

ملف واحد، أزرار كبيرة للمس، من غير مكتبات.
```

---

## محادثة التعديل (رسالة برسالة)

### رسالة 1
الصق البرومبت النهائي (بعد ما تغيّر الأسئلة لاسم الطفل).

### رسالة 2 — لو الأزرار صغيرة
```
في نفس الملف: كبّر أزرار الإجابات عشان تبقى سهلة للمس.
```

### رسالة 3 — لو عايز أسئلة أكتر
```
ضيف سؤالين كمان بنفس الشكل (4 اختيارات + نجمة على الصح).
```
