# حصة 7 — لعبة تجنّب العقبات 🏃

**النتيجة:** [`../examples/game-obstacles.html`](../examples/game-obstacles.html)

---

## البرومبت النهائي (انسخ)

```
اعمل لعبة HTML واحدة بالعربي: طفل ابتدائي أسفل الشاشة (رسم SVG جوه الملف).
أزرار يمين وشمال واضحة الاتجاه + أسهم الكيبورد.
حواجز تنزل من فوق. لمس الحاجز = نهاية.
كل حاجز تعدّيه = نقطة. زر إعادة. ملف واحد، مناسب للمس.
```

---

## محادثة التعديل (رسالة برسالة)

### رسالة 1 — البداية
```
اعمل لعبة HTML واحدة بالعربي: شخصية أسفل الشاشة.
أزرار يمين وشمال + أسهم الكيبورد.
حواجز تنزل من فوق. لمس الحاجز = نهاية.
كل حاجز تعدّيه = نقطة. ملف واحد.
```

### رسالة 2 — الشخصية
```
غيّر شخصية اللاعب من موتوسيكل لرسم طفل ابتدائي
(يونيفورم أزرق + شنطة). استخدم SVG جوه الملف، من غير صور خارجية.
```

### رسالة 3 — الاتجاه
```
الأزرار والأسهم معكوسة.
يمين يحرّك يمين، شمال يحرّك شمال.
اكتب على الأزرار: يمين وشمال عشان تبقى واضحة.
```
