# تعديلات عامة — أي يوم / أي لعبة

استخدمها لما الطفل يقول «مش عاجبني» من غير ما يلخبط الملف كله.

---

## خط وأزرار
```
في نفس الملف، من غير ما تغير المحتوى:
- كبّر العنوان
- خلّي الزر أسهل للمس
```

---

## حاجة مش شغالة
```
صلّح ___ بس. متغيّرش باقي الصفحة.
```

---

## شكل أحلى
```
في نفس الملف: خلّي الألوان أوضح والخط أكبر.
```

---

## بطاقة سريعة للطفل

| لو… | قول |
|------|------|
| الشكل وحش | «خلّي الألوان أوضح والخط أكبر» |
| حاجة مش شغالة | «صلّح ___ بس، متغيّرش الباقي» |
| عايز أصعب | «بعد كل 20 نقطة خلّي اللعبة أسرع شوية» |
| عايز أجمل | «غيّر الرسم لـ ___ من غير مكتبات» |
| لسه ناقص | «ضيف ___ بس. متلمسش باقي الصفحة» |
