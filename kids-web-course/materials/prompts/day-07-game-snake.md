# حصة 7 — لعبة الدودة والسكر 🐍

**النتيجة:** [`../examples/game-snake.html`](../examples/game-snake.html)

---

## البرومبت النهائي (انسخ)

```
اعمل لعبة HTML واحدة بالعربي: الدودة بتاكل سكر.
لوحة مربعات. الأسهم تحرّك الدودة + أزرار على الشاشة.
كل سكرة = نقطة وتطوّل.
لما توصل لحد اللوحة تطلع من الناحية التانية.
الاصطدام بالجسم بس = نهاية + عرض النقاط.
ألوان فاقعة، ملف واحد، لطفل 9 سنين.
```

---

## محادثة التعديل (رسالة برسالة)

### رسالة 1 — البداية
```
اعمل لعبة HTML واحدة بالعربي: الدودة بتاكل سكر.
لوحة مربعات. الأسهم + أزرار على الشاشة.
كل سكرة = نقطة وتطوّل.
الاصطدام بالجدار أو الجسم = نهاية. ملف واحد.
```

### رسالة 2 — الحواف
```
لما الدودة توصل لحد اللوحة، متتنهيش.
طلعها من الناحية التانية (فوق↔تحت، يمين↔شمال).
اللعبة تنتهي بس لو لمست جسمها.
```
