# إضافي — صفحة شخصية زي فيسبوك

**النتيجة:** [`../examples/facebook-profile.html`](../examples/facebook-profile.html)

---

## البرومبت النهائي (انسخ)

```
اعمل صفحة HTML واحدة بالعربي dir="rtl" تشبه صفحة شخصية على فيسبوك (مش حساب حقيقي — مجرد شكل).

فيها:
- شريط فوق أزرق/أبيض بشعار بسيط ومربع بحث
- صورة غلاف ملونة كبيرة
- صورة شخصية دائرية (إيموجي) + الاسم + عدد أصدقاء
- أزرار: أضف صديق / رسالة
- تبويبات: منشورات · حول · صور · أصدقاء
- عمود يمين: معلومات عني + شبكة صور صغيرة + أصدقاء
- عمود شمال: صندوق «بم تفكّر؟» + 3 منشورات (نص + إعجابات + أزرار أعجبني/تعليق/مشاركة)

البيانات:
الاسم: أندرو
السن: 9
الكنيسة: مارجرجس مطار النزهة
الهوايات: كرة القدم، الرسم، الألعاب، القصص
حلمي: أعمل لعبة ويب لأصحابي

ألوان قريبة من فيسبوك (#1877f2 + خلفية رمادي فاتح).
خط واضح، مناسب لطفل 9 سنين. من غير مكتبات خارجية. ملف واحد.
الزر «أضف صديق» يغيّر النص لما يتضغط. زر أعجبني يزوّد الرقم.
```

---

## محادثة التعديل (رسالة برسالة)

### رسالة 1 — بداية
```
اعمل صفحة HTML واحدة بالعربي تشبه صفحة شخصية على فيسبوك
(شكل فقط، مش حساب حقيقي):
غلاف + صورة شخصية + اسم + أزرار أضف صديق ورسالة +
منشورات + أعجبني. الاسم أندرو، 9 سنين. ملف واحد.
```

### رسالة 2 — أقرب للشكل
```
ضيف شريط فوق، تبويبات (منشورات · حول · صور · أصدقاء)،
عمود معلومات + صور، و3 منشورات جاهزة.
زر أضف صديق يغيّر النص لما يتضغط، وأعجبني يزوّد الرقم.
```
